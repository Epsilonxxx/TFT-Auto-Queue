# TFT-Auto-Queue

## 中文介绍

TFT-Auto-Queue 是一个适用于 LOL 国际服云顶之弈 的轻量桌面工具，主要用于 发条鸟试炼模式自动匹配。  
它可以自动处理重复操作，例如创建房间、开始匹配、接受对局，以及在对局结束后继续下一轮。

软件内置基础异常恢复能力，可在部分匹配失败、客户端重连异常、房间状态异常等场景下自动处理，尽量减少手动干预。  
同时支持 本地配置保存、中英文切换、F1 一键启动/关闭，适合长时间循环使用。

控制台支持查看客户端连接状态、当前阶段、运行时长、重试倒计时、累计统计和最近 80 条活动。设置按基础、时序、恢复分组，支持中英文和窄窗口布局。

## 主要功能

- 自动匹配发条鸟试炼
- 自动接受准备确认
- 对局结束后自动继续
- 匹配失败后自动冷却重试
- 连接异常时自动回房并重新匹配
- 客户端崩溃弹窗自动跳过恢复
- 循环次数统计

## 使用

1. 启动 LOL 客户端并完成登录。
2. 打开软件，可先点击“检查客户端”确认连接。
3. 点击“启动自动匹配”，或按 F1 开始；再次按 F1 停止。
4. 关闭主窗口后软件继续在托盘运行，从托盘菜单退出才会结束程序。

默认单局超时时长为 300 秒。达到时限会强制关闭游戏进程，并在客户端允许返回房间后继续匹配；正常对局也会触发。可在“偏好设置 → 恢复”调整。客户端仍判定上一局有效时，软件会等待客户端状态更新，无法绕过服务器对局状态。

客户端识别使用进程命令行与 C 至 Z 盘标准目录下的 lockfile 回退。没有重新启用此前撤回的 Riot 元数据扫描、手动安装路径、配置备份恢复功能。

## 开发与验证

```powershell
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:ui
npm start
```

`npm test` 覆盖匹配循环、异常重连、入队失败、超时退出、停止取消、LCU 发现与表单校验；Windows 上还会使用系统 PowerShell 解析恢复脚本，测试不执行点击或结束游戏操作。

`npm run test:ui` 使用模拟客户端测试界面交互、保存设置、中英文和四种窗口宽度，截图输出到 `artifacts/ui/`。真实 Electron 的预加载、IPC 和客户端检查需要配合实际客户端验证；模拟测试不代表已通过在线对局实测。

```powershell
npm run dist
```

安装包输出到 `release/`。`npm run icons` 可从 `assets/app-icon.svg` 重新生成 Windows 与托盘图标。
