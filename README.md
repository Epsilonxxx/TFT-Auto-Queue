# TFT Auto Queue

适用于 Windows 的 LOL 国际服云顶之弈自动匹配工具，主要用于发条鸟的试炼。

[下载安装包](https://github.com/Epsilonxxx/TFT-Auto-Queue/releases/latest) · [更新日志](CHANGELOG.md)

## 主要功能

- 自动创建房间、开始匹配、接受对局，结束后继续下一轮。
- 入队失败冷却重试、客户端断连重试与崩溃报告弹窗自动处理。
- 单局超时退出并尝试恢复匹配，超时时长可调。
- 客户端连接检查、实时阶段、运行时长、恢复倒计时、活动记录与场次统计。
- 中英文界面、分组设置、F1 快捷启停和托盘后台运行。

## 使用方法

1. 启动 LOL 客户端并完成登录。
2. 打开软件，点击“检查客户端”确认连接。
3. 点击“启动自动匹配”或按 **F1** 开始，再次按 **F1** 停止。

关闭窗口后软件仍在托盘运行，右键托盘图标选择“退出”可结束程序。

**默认单局超时为 5 分钟，正常对局也会触发强制退出。** 可在“偏好设置 → 恢复”调整；退出后需等待客户端允许回房才能继续匹配。


界面测试使用 `npm run test:ui`，首次运行前执行 `npx playwright install chromium`。
